---
name: organize-book
description: Maintain the book’s reference areas, records, and author decisions.
---
Read book_outline first. Use the active record and area when the author refers to “this entry” or “this area.” Check book_canon and book_review before creating or moving records.

Use the book type to interpret the request. In fiction, distinguish people, places, groups, events and relationships. In a rulebook, keep terminology, procedures, worked examples and exceptions distinguishable. In a supplement, link setting information to encounters, clues or handouts when the text supports it. Keep related records together unless the author requests a distinct area.

Use book_manage_area for a new area or a rename. Rename in place to preserve links and existing content. When removing a populated area, establish where its contents should go. For explicit author direction, Chat queues a Canon Keeper assignment with source_refs selected from book_author_passages. The Keeper selects supporting passages from its assignment and calls book_record_author_fact with their source_refs and structured template fields. This path works with an empty manuscript. Use book_propose_finding for manuscript evidence and book_answer_question for the author's answer to an existing question. Leave uncertain facts and empty lists out. Verify the resulting IDs with book_canon.

To design or revise an area template, create the area if needed, then use book_read_template. Choose fields according to how the author will use the entries. Use text for a single answer and list for repeatable items. Give each field a stable lowercase key, a short label, and specific guidance. Use book_set_template with the current revision and the complete ordered field list. Preserve keys when relabeling. Fields with saved content must remain compatible until the author decides how to migrate their values. Confirm the saved template by reading it back.

Use the links format for references to people, places, factions, rules, or other canon entries. Each link has a name, context describing the direction of the relationship, and a target_id when resolved. Search book_find_entries first, including aliases and pending entries. Use stable IDs even when names repeat. Check the source to distinguish namesakes. Leave target_id absent for an unresolved mention and ask the author when the distinction matters. To enrich an existing book, inventory the entries first, read their source sections, then submit cited proposals for manuscript changes or add supported links to author entries with book_record_author_fact. For a multi-entry extraction, save proposals first, then make a second pass to connect entries created later. Preserve pending review status. Look up incoming references with book_find_entries using links_to. A backlink establishes a reference; it does not establish a reciprocal allegiance or opinion.
