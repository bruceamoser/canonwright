# CanonWright skills

| Skill | Books | Output |
| --- | --- | --- |
| Extract characters | Novel, content book | Character, alias, relationship, and motivation proposals |
| Extract locations | Novel, content book | Towns, sites, regions, and connections |
| Extract factions | Novel, content book | Groups, goals, influence, and affiliations |
| Extract rules | Rulebook, content book | Terms, procedures, outcomes, and examples |
| Extract adventure content | Content book | Encounters, clues, tables, and handouts |
| Review section | All | Evidence-based editorial findings and questions |
| Organize book | All | Reference areas, record changes, and author decisions |
| Create a skill | All | Draft SKILL.md for the author to review and save |
| Writing conversation | All | Editorial conversation and dispatch to the appropriate skill |

Extraction and review use the open source section and relevant project records. A skill's Markdown supplies the writing method. The app supplies the input and output contract and validates evidence against the source.
